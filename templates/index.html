Project Summary & Objectives

Title: CyberGuard AI-Based Phishing URL & Website Detector

Goal: Provide security analysts and enterprise environments with instantaneous, explainable threat assessments before untrusted links are clicked in emails, SMS, messaging platforms, or web applications.

Core Problem: Phishing attacks remain the leading root cause of credential theft, session hijacking, and ransomware initial access. Attackers leverage deceptive subdomains, raw IP hosting, URL shorteners, punycode spoofing, and social engineering keywords to bypass traditional static blacklists.

Interactive System Architecture Pipeline
Zero-Network Execution Rule
URLs are parsed strictly as offline character vectors without making external HTTP requests, resolving remote DOMs, or executing client JavaScript, eliminating SSRF and drive-by malware vectors.
Transparent Explainability
Rather than treating the classifier as a black box, the inference engine generates human-readable security indicators detailing why a threat score was assigned.
Academic Rigor & Benchmark
Trained on a balanced 10,000-sample corpus with 80/20 train/test stratified isolation. Preprocessing scalers are strictly fitted on training partitions to prevent data leakage.
